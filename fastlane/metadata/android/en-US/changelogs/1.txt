Initial release.

- Connect to FTMS-compatible treadmills and indoor bikes
- Heart rate sensor support via BLE (Gadgetbridge compatible)
- Real-time dashboard with speed, cadence, power, distance, HR, energy
- Session recording to local database
- Debug Bluetooth communication logging
- BH Fitness device support
- Portrait and landscape layouts
- Workout controls: Start / Pause / Resume / Stop buttons, shown when a device is connected
- Auto-detect device type: HR-only devices (e.g. Xiaomi Smart Band) connect automatically as HR sensor
- HR signal shown live from dedicated HR sensor even without an FTMS machine
- Workouts can be started with only a HR sensor connected (HR-only mode)
- Session summary (avg/max speed, power, HR) saved on workout completion
- Workout History screen with a list of all past workouts
- Export workouts as FIT or CSV from the History screen (FIT replaces GPX for full indoor data)
- FIT export includes per-second records with speed, cadence, power, HR, distance, grade and resistance; consecutive identical samples are deduplicated
- Device info (MAC address, serial number, hardware and firmware revision) shown when connected to a FTMS device, hidden if not available
- Delete past workouts via long-press
- BH Fitness iConcept 3.0 treadmill now supported — connect and start using it
- Session recording starts and stops automatically when the machine starts or stops
- Fixed: GATT operation queue serialised — all CCCD subscriptions and characteristic reads now complete reliably (fixes no data on BH Fitness and similar devices)
- Audio Bluetooth devices (earbuds, headphones) are now hidden from the scan list
- Previously connected devices remain visible in the list after disconnect, with a Reconnect button — no need to re-scan
- Fixed: dashboard metrics are cleared when device disconnects
- Show notification when device unexpectedly disconnects
